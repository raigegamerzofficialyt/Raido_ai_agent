# Hook patterns (first 3 seconds)

- **Question the viewer already has:** "Phone ki battery jaldi kyun khatam hoti hai?"
- **Surprising verified fact:** state it plainly, then promise the explanation. Only with a verified source.
- **Problem -> promise:** "Ye galti 90% log karte hain" is NOT allowed unless you have a source for the number. Prefer "Ye ek galti bahut common hai".
- **Result first:** show the finished outcome for 2 seconds, then rewind to how.
- **Direct challenge:** "30 second me samjhata hoon, agar samajh na aaye to repeat dekho."

# Structures

**Short (vertical):** Hook (0-3s) -> one idea in 2-4 punchy beats -> payoff -> loop-friendly last line.

**Long (landscape):** Hook (0-15s) -> promise/roadmap -> 3-5 sections with a mini-payoff each -> recap -> CTA. Add a pattern interrupt (new visual, B-roll, text card) every 10-20 seconds.
